# اتكلم | EtKallem English

تطبيق لتعلم المحادثات الإنجليزية بالعربية: جمل يومية وشغل وتراخيص وتصاريح، سماع النطق، تسجيل المحاولة، اختبارات وحفظ التقدم.

سيتم بناء APK تجريبي تلقائيًا عبر GitHub Actions من المسار `.github/workflows/build-apk.yml`.

تحميل التطبيق بعد نجاح البناء من تبويب **Actions** ← **Build Android APK** ← **EtKallem-Android-APK** (ZIP يحتوي `app-debug.apk`).
