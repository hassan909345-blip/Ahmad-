# اتكلم | EtKallem English

تطبيق Android لتعليم الإنجليزية بالعربي في الحياة والعمل.

## المزايا
- 148 جملة مترجمة للعربية موزعة على 8 أقسام، تشمل العمل والاجتماعات والتصاريح.
- استماع بصوت إنجليزي طبيعي عبر المحرك المثبّت على الجهاز (Android TextToSpeech).
- تشغيل بطيء أو بالتسلسل، ومحادثات كاملة، والتدريب على الكلام عن طريق نظام التعرف الصوتي.
- اختبار الجمل، حفظ المفضلة والتقدّم محليًا دون الحاجة إلى حساب.
- دروس Offline. التدريب على الميكروفون قد يحتاج الإنترنت حسب خدمة الهاتف.

## إنشاء ملف APK
1. افتح **Actions** في هذا المستودع.
2. ادخل على Workflow باسم **Build Android APK** ثم أحدث تشغيل ناجح.
3. نزّل Artifact باسم **EtKallem-Android-APK**، فك الضغط وثبّت **app-debug.apk**.

أو افتح المشروع باستخدام Android Studio وابنِ APK من Build.

النسخة الحالية Debug (للتجربة الشخصية) وليست إصدار متجر Google Play موقّعًا للإنتاج.
